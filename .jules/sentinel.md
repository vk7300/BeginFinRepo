## 2024-03-24 - Certificate Issuance Authorization Bypass via Fallback Logic
**Vulnerability:** The `/api/issue-certificate` endpoint contains an insecure graceful fallback mechanism. If a user's `completedModules` array is empty on the server, the application inadvertently trusts and uses the `completedModules` array provided in the client's request body (`req.body.completedModules`).
  **Learning:** This vulnerability exists because of an attempt to gracefully handle environments where the Admin SDK lacks IAM permissions. However, by blindly falling back to client-provided data when the server-side check yields an empty array, it completely bypasses the intended server-side verification of course completion. An attacker can simply clear their server-side progress and supply a forged payload indicating full completion to receive a valid certificate.
**Detection:** Look for fallback logic that conditionally trusts client input (`req.body`) when server-side queries fail or return empty results, especially in endpoints handling authorization or credential issuance.
